# Studio Sozo — Complete Logo Package

Identity: **Studio Sozo**  |  Website: **studiosozo.dev**

## What's included

- `SVG/`: genuine traced vector paths, no embedded bitmaps, black and white variants.
- `PNG/Black/` and `PNG/White/`: transparent high-resolution artwork.
- `JPG/Light-Background/` and `JPG/Dark-Background/`: opaque presentation-ready images.
- `Web-Icons/`: browser favicon, apple touch icon and app/social sizes.
- `Previews/`: overview image for quick reference.
- `Brand-Guidelines/`: three-page PDF with practical brand usage rules.

## Logo arrangements

- **primary-horizontal**: icon to the left of two-line Studio Sozo wordmark; default for website and documents.
- **stacked**: icon above wordmark; good for portrait/vertical contexts.
- **icon**: geometric S symbol on its own; good for favicons and social avatars.
- **wordmark-stacked**: two-line type-only mark.
- **wordmark-inline**: one-line wordmark built from approved lettering.

## Usage

- On light backgrounds, use **black** artwork.
- On dark backgrounds, use **white** artwork.
- PNG files contain actual transparency: white art may look invisible on a white image viewer.
- SVG files have actual editable vector paths, not embedded raster images. This artwork was traced from the most recently approved brand presentation; use the vectors for production resizing.
- JPGs cannot store transparency, so they include a solid black or white background.
- For the website, prefer SVG in the navbar and PNG favicon variants as needed.

## Design foundation

Primary: #000000  |  Secondary: #FFFFFF
Visual style: geometric, minimal, rounded, monochrome.
